# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this
project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-25

- First public release.
- Run the local Payroof stack (Anvil, Payroof, Stor, Wallet) with `roofer up` and `roofer down`.
- Faucet and token tools: fund, send, balance, mine, and deploy ERC-20 tokens.
- Build and launch the Wallet on a paired iPhone with `roofer ios`.
- End-to-end tests and hardened container checks, plus a guided walkthrough with `roofer guide`.
